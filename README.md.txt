       # QSPR Models for Octacene Using Degree-Based Topological Indices
       
       ## Overview
       
       This repository contains the code and data for the paper:
       
       **"Degree-Based Topological Indices and Graph Entropy Measures for Octacene: A 
QSPR-Oriented Analysis with Machine Learning Validation"**
       
       **Authors:** Iqra Yaqoot, Zeeshan Saleem Mufti, Gamachu Adugna Ganati
       
       **Corresponding Author:** gammeekoo@gmail.com
       
       ## Repository Contents
       
       | File | Description |
       |------|-------------|
       | `paper.tex` | LaTeX source of the paper |
       | `main.py` | Python code for Random Forest QSPR models |
       | `expanded_dataset.csv` | Expanded 28-PAH dataset with topological indices and 
HOMO-LUMO gaps |
       | `requirements.txt` | Python package dependencies |
       | `LICENSE` | MIT License |
       
       ## Requirements
       
       - Python 3.8 or higher
       - scikit-learn 1.x
       - numpy
       - pandas
